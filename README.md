# 🎬 Movie Recommendation System

## 📌 Overview
This is a simple **Movie Recommendation System** project built using Machine Learning techniques.  
It recommends movies based on user preferences using similarity measures.

---

## 💡 Objective
To suggest movies similar to a given movie using data-driven recommendation techniques.

---

## 🛠️ Technologies Used
- Python 🐍  
- Pandas  
- NumPy  
- Scikit-learn  
- Jupyter Notebook  

---

## 📊 Dataset
The dataset contains movie details such as:
- Title  
- Genre  
- Overview / Description  
- Keywords (if available)

---

## ⚙️ How It Works
1. Data is collected and cleaned  
2. Features like genres/overview are processed  
3. Text is converted into vectors using NLP techniques  
4. Similarity score is calculated  
5. Movies with highest similarity are recommended  

---

## 📁 Project File
- `movie_recommendation_project.ipynb` → Main project notebook  

---

## 🚀 How to Run
1. Clone the repository  
2. Open the notebook in Jupyter / Google Colab  
3. Run all cells step by step  
4. Enter a movie name to get recommendations
